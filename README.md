# DeepNick · Algorithm Lab

一个独立的个人算法博客静态站点，包含：

- 牛客 / AtCoder / Codeforces 题解列表与大屏详情阅读器
- 题解平台雷达、短笔记标签筛选、时间线
- 深色 / 浅色主题切换、滚动渐显、响应式移动端布局
- 无构建依赖，直接双击 `index.html` 即可预览

## 文件结构

- `index.html`：页面结构与内容
- `styles.css`：视觉样式与响应式布局
- `data.js`：可上传到 GitHub Pages 的公开数据源（比赛、题目、笔记、资料等）
- `app.js`：筛选、弹窗、主题交互与本地编辑器

## 自定义入口

打开页面后，点击“＋ 新建题解”即可发布一场比赛。编辑器提供 A 到 L 的独立字母按钮，可以任意组合选择，例如 A、C、F、K，不要求连续。每个已选字母都会生成独立编辑卡片，可以分别填写题目名称、知识点、正文和代码。点击比赛卡片会进入大屏阅读器，通过题号导航查看详细题解。比赛右侧的铅笔按钮可以编辑，× 可以删除。

## 发布到 GitHub Pages

将 `index.html`、`styles.css`、`app.js`、`data.js` 以及其余脚本放在同一个仓库目录，开启 GitHub Pages 后即可访问。首次打开会从 `data.js` 初始化内容；浏览器中的编辑会暂存在本地，修改公开内容时直接编辑 `data.js` 后提交 GitHub。

页脚右下角的“同步 data.js”按钮可以把当前浏览器里的最新数据导出为 `data.js` 文件，替换仓库中的旧文件并提交即可发布。

页面中的个人资料、分类、平台、欢迎语、短笔记、时间线、关于我和页脚区域都会显示“编辑”按钮。时间线会自动显示每场比赛的日期、比赛名称和题解数量；你也可以在时间线编辑器中追加自己的事件。点击比赛后进入大屏阅读器，可通过题号导航切换题目；代码区采用 VS Code Dark+ 风格配色、行号和等宽字体。笔记和时间线采用逐条卡片编辑，可添加或删除单条内容。修改内容会保存到浏览器的 `localStorage`，刷新页面仍然保留。若要恢复初始示例数据，可在浏览器开发者工具中执行 `localStorage.removeItem('deepnick-blog-data')` 后刷新。

个人资料编辑窗口支持上传本地头像，图片会显示在 DN 圆圈内；也支持上传顶部背景图。
