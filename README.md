# DeepNick · Algorithm Lab

一个独立的个人算法博客静态站点，包含：

- 牛客 / AtCoder / Codeforces 题解列表与 **全屏题解阅读页**
- 代码自动上色（VS Code Dark+ 配色）、一键复制、深链直达某道题
- 短笔记标签筛选、时间线、个人资料与分类编辑
- 深色 / 浅色主题切换（并记住你的选择）、滚动渐显、响应式移动端布局
- 图片上传自动压缩、本地编辑器
- 无构建依赖，直接双击 `index.html` 即可预览

## 文件结构

- `index.html`：页面结构与内容
- `styles.css`：视觉样式与响应式布局
- `app.js`：题解数据、筛选、全屏阅读、语法高亮、主题、本地编辑器与“内嵌数据”逻辑
- `data.js`：**内嵌内容数据**（见下方“如何让别人看到你的内容”）
- `range-fix.js` / `clear-image.js` / `custom-editor.js`：编辑器范围选择、图片清除、自定义多题编辑器等辅助逻辑

## 如何让别人看到你的内容（重要）

本站内容默认存在**你自己浏览器**的 `localStorage` 里，别人直接打开网页看到的是示例数据。要让别人看到你的内容，用页面底部的 **「📦 内嵌数据(生成 data.js)」** 按钮：

1. 打开 `index.html`，先写好/编辑好你的比赛、笔记、资料。
2. 点页面底部 **「📦 内嵌数据(生成 data.js)」**，浏览器会下载一个 `data.js`。
3. 把这个 `data.js` 放到 `index.html` 所在文件夹（覆盖同名占位文件）。
4. 把整个文件夹发给别人 / 发布到服务器即可 —— **对方打开网页就能直接看到你的全部内容，无需导入。**

要点：
- `data.js` 存的是 `window.__DEEPNICK_DATA__ = { ... }`，页面加载时优先读取它作为基础内容。
- 你自己继续编辑时，本地 `localStorage` 仍会覆盖在 `data.js` 之上，无需每次都重建；想“发布”最新内容时再点一下按钮重新生成 `data.js`。
- `data.js` 同时可以当作你的备份。

## 内容编辑

打开页面后，点击“＋ 新建题解”即可发布一场比赛。编辑器提供 A 到 L 的独立字母按钮，可以任意组合选择，例如 A、C、F、K，不要求连续。每个已选字母都会生成独立编辑卡片，可以分别填写题目名称、知识点、正文和代码。点击比赛卡片会进入全屏题解阅读页，展开字母即可查看详细题解；每个代码块是一键复制的 VS Code 风格窗口。比赛右侧的铅笔按钮可以编辑，× 可以删除。

页面中的个人资料、分类、平台、欢迎语、短笔记、时间线、关于我和页脚区域都会显示“编辑”按钮。时间线会自动显示每场比赛的日期、比赛名称和题解数量；你也可以在时间线编辑器中追加自己的事件。笔记和时间线采用逐条卡片编辑，可添加或删除单条内容。修改内容会保存到浏览器的 `localStorage`，刷新页面仍然保留。若要恢复初始示例数据，可在浏览器开发者工具中执行 `localStorage.removeItem('deepnick-blog-data')` 后刷新。

## 其它小功能

- **深链**：打开某场比赛会在地址栏生成 `...#solution/比赛id`，甚至可以加 `/字母`（如 `...#solution/c1/B`）直接定位到具体题目，可分享、可刷新恢复。
- **主题记忆**：深/浅主题选择会保存到 `localStorage`，刷新后保持。
- **图片压缩**：上传头像/背景图时会自动压缩，避免撑爆 `localStorage` 容量限制。
